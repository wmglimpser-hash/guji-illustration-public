快速启动

⚠️
不要直接双击打开 index.html。必须通过 bridge.py 启动本地服务后，在浏览器访问 http://localhost:5678/。file:// 协议下 pdf.js 和 AI 请求均无法工作。
首次运行（四步完成）
# 0. 克隆仓库
git clone https://github.com/wmglimpser-hash/guji-illustration.git
cd guji-illustration/demo

# 1. 安装 Python 依赖
pip install -r requirements.txt

# 2. 下载 pdf.js 本地依赖（需联网，约 2MB，仅首次）
python download_pdfjs.py

# 3. 配置 AI 接口
cp config.example.json config.json
# 用文本编辑器打开 config.json，填写 api_provider 和 api_key

# 4. 启动服务
python bridge.py

启动成功后终端显示 * Running on http://0.0.0.0:5678，随后在浏览器打开 http://localhost:5678/

日常启动（已配置后）
cd guji-illustration/demo
python bridge.py

已导入的书籍和标注数据会自动恢复，无需重新导入。

1

第一步：导入书籍

  1. 1
    点击顶部「📖 导入书籍」按钮打开导入弹窗，切换到「从 PDF 提取」选项卡。
  2. 2
    填写书籍元数据：书名（如：补遗雷公炮制便览）、朝代（明）、版本（如：万历七年刊本）。
  3. 3
    选择本地 PDF 文件，点击「开始导入」。工具自动建立全书页面索引、生成缩略图，并尽量提取 PDF 文字层。
  4. 4
    导入完成后，可点「打开全书」浏览所有页面的缩略图。PDF 已同步上传至 bridge，刷新页面后无需重新导入。
💡
PDF 持久化：导入时 PDF 自动保存到 demo/data/pdfs/，之后通过 book.pdfStorage.url 自动恢复，OCR 和页面渲染不会因刷新中断。
2

第二步：准备页面文字

AI 标注采用图文互证模式：同时发送插图和页面文字给 AI，让它判断图文是否一致。运行 AI 标注前需确保页面有文字资产。

三种文字来源处理方式

情况文字状态处理方式
PDF 含原生文字层textStatus: extracted导入时自动提取，无需额外操作
扫描件，无文字层textStatus: missing点击「候选页 OCR」批量调用 AI 识别
手动录入—在右侧「原文对照」面板直接粘贴原文

原文对照面板操作

📝 原文对照面板是唯一文字编辑工作区
  • ↓ 整页原文作关联段落：将整页全文设为当前图像的关联文字，发送给 AI 时作为上下文
  • ✂ 用选区设为关联段落：在文字框中选中某一段落后点此按钮，截取最相关的文字片段

设计原则：页面文字是页面级资产，插图标注只消费（引用）它，不复制一份到图像对象上。

候选页 OCR

候选页 OCR 按钮处理当前书的全部候选插图页（非整本全文 OCR）。推荐在识别插图之后执行，流程如下：

  1. 尝试刷新图像区域（cropRect）
  2. 有 PDF 文字层时直接写入 textAsset.fullText
  3. 无文字层时调用 /api/extract-page-text 生成页面 OCR 文本
3

第三步：识别插图候选页

在书籍详情页点击「识别插图」，工具扫描全书所有页面，自动标记含插图页面，生成候选页子集。

💡
建议先点「打开全书」浏览完整页面预览，确认识别准确性后，再决定是否对整本或单页执行插图识别。候选页结果保存在 book.illustrationPages。
全书浏览模式

弹出全书浏览层后，可以：

  • 查看每页缩略图，直观判断是否含插图
  • 手动勾选/取消候选页
  • 为单页设置裁图区域（cropRect）
  • 触发单页 OCR
4

第四步：AI 候选标注

点击图像旁的「AI 标注」触发单张标注，或在书籍详情页批量运行（「批量标注」）。

发送内容策略

场景发送内容
有关联文字裁图 + 关联段落文字（优先）
有全页文字但无关联段落裁图 + 全页文字
无文字层（扫描件）裁图 + 全页图（双图模式）

结果双轨保存

字段说明
aiDraftAI 原始输出快照，首次写入后不被人工操作覆盖，可用于后续评估 AI 准确率
annotation当前可编辑版本，专家可直接修改所有字段
aiVerdict图文互证判断：一致 存疑 矛盾，以颜色卡片展示
crossref人工录入的互证记录，独立于 AI 字段

图文互证门禁

运行 AI 标注时有两级门禁检查：

  • 一级：textStatus === 'missing' → 弹出提醒，建议先提取文字后再标注
  • 二级：有全文但未截取关联段落 → 提示截取，或选择直接用全文继续

模型能力要求

本工具对 AI 模型有两项核心要求：

  • 视觉理解：能接收图像输入并描述内容（Vision / Multimodal）
  • 中文古籍文字识别：能识别繁体汉字、竖排文本，理解古汉语词汇

不具备图像输入能力的纯文本模型（如 DeepSeek 文本版）无法用于标注，系统会自动提示。

支持的 AI 提供商

提供商api_provider 值常用模型示例说明

以上为常见可用模型，各平台持续迭代，具体模型名称以各平台官方文档为准。配置时填入 config.json 的 model 字段即可切换，无需修改代码。

5

第五步：专家核查

在前端标注主区逐条审阅 AI 候选标注，修正字段，确认图文互证结论。

标注字段说明

字段含义取值示例
academic_class图像类型（12 类学术分类，据胡晓峰《历代中医古籍图像类编》）疾病图 / 诊法图 / 医疗图 / 药物图 / 器具图 / 养生图 / 脏腑图 / 经穴图 / 部位图 / 理论图 / 符咒图 / 人物图
herb_name主体药材名（正名）人參、白术
aliases别名列表["沙参", "野人参"]
procedure_step炮制工序描述研末、蒸制、炒黄
aiVerdict图文互证结论一致 / 存疑 / 矛盾
confidenceAI 置信度high / medium / low
note专家备注自由文本

核查操作

操作状态变化说明
点击「✓ 确认」已确认标注通过审核，human_verified=true
点击「✗ 有问题」有问题标记此条需要重新处理
直接修改字段保持当前状态字段修改自动保存，AI 草稿不受影响

差异追踪

系统自动追踪人工修改相对于 AI 草稿的差异（review_diff），导出时实时计算，可量化各字段 AI 准确率，适用于系统评估与一致性分析。

6

第六步：导出数据

点击顶部「导出数据」打开导出面板，可按范围（全部书籍 / 当前书籍）、状态（全部 / 已标注 / 已确认）、模型筛选记录，预览条数后选择导出格式：

格式说明
JSONL（完整数据）全部记录，含未确认条目
JSONL（已确认）仅 human_verified=true 的记录
CSV扁平表格，可直接用 Excel 打开
HTML 报告单文件图文并排可视化报告
图文互证记录仅含 crossref 原文对照条目

JSONL 记录结构

{
  "annotation": { // 当前人工最终版（全部字段）
    "image_type": "PROCESSED",
    "herb_name": "人參",
    "procedure_step": "研末",
    "aiVerdict": "一致"
  },
  "ai_draft": { // AI 原始输出（运行过 AI 时存在）
    ...
  },
  "review_diff": { // 字段级差异，导出时实时计算
    "herb_name": { "ai": "参", "human": "人參" }
  },
  "crossref": { // 人工图文互证记录
    "classical": "人參，根如人形，有須……",
    "verdict": "一致",
    "note": ""
  },
  "human_verified": true  // status === 'ok' 时为 true
}

命令行批量标注

不启动前端时，可直接用 annotate.py 批量处理已提取的图像文件夹。

# Mock 模式（不调用真实 API，用于调试）
python demo/annotate.py --mock

# 真实标注
python demo/annotate.py --input data/extracted/ --config demo/config.json

推荐输入目录结构

data/extracted/
├── page_001_crop.png       ← 裁图（必须）
├── page_001_crop.txt       ← 关联文字（优先使用）
└── page_001_crop_page.png  ← 全页图（可选，无文字层时作第二图送 AI）

文字上下文优先级

  1. 输入 JSON 中显式提供的 page_context 字段
  2. 同名旁白 .txt 文件
  3. 显式指定的 full_page_path
  4. 约定式 sidecar：xxx.page.png / xxx_page.png 等
  5. 降级：仅图像模式（输出低置信度）

输出

结果写入 output/ 目录：report.html（可视化）+ annotations.jsonl（结构化数据）。

Bridge API 端点

bridge.py 在本地运行 HTTP 服务（默认端口 5678），代理所有 AI 请求，解决浏览器 CORS 限制。

端点方法用途
/GET返回前端工作台页面
/guideGET返回本使用指南
/api/statusGET服务状态与配置检查
/api/sessionGET / POST完整 state 读写
/api/upload-imagePOST上传图像，返回本地 URL
/api/upload-pdfPOST上传 PDF，保存至 data/pdfs/
/api/extract-page-textPOST页面 AI OCR（发送 page_b64，返回 full_text）
/api/annotatePOST图文互证标注（裁图+文字/页图 → 结构化 JSON）
/api/store-model-runPOST持久化 AI 标注结果到 model_runs/
/api/model-runsGET读取历史 AI 运行记录
/data/images/<file>GET图像静态服务
/data/pdfs/<file>GETPDF 静态服务

常见问题

Q：导入 PDF 后刷新页面，书籍消失了？

重新导入一次即可触发 PDF 持久化，此后刷新自动恢复。旧版本（2026 年 5 月之前导入）需要重导一次以写入 pdfStorage.url 字段。

Q：AI 标注返回低置信度？

系统检测到页面文字缺失，已降级为纯图像模式。建议先在「原文对照」面板补充文字后重新标注，或先执行「候选页 OCR」。

Q：bridge.py 端口被占用？

修改 bridge.py 末尾 app.run(port=5678) 中的端口号，同时更新前端访问地址。

Q：如何更换 AI 模型？

推荐在前端右上角「⚙ 设置」面板中切换，点击「保存配置」即持久生效。也可直接编辑 demo/config.json，修改 api_provider 和 model 字段，保存后重启 bridge 生效。

Q：config.json 会被提交到 git 吗？

不会，已加入 .gitignore。API Key 安全。

Q：如何备份所有标注数据？

复制整个 demo/data/ 目录即可（含各书 books/ 子目录、图像、PDF、AI 运行记录）。也可通过「导出数据」→「JSONL 全量」导出所有条目为独立文件。

Q：如何在多台电脑之间共享数据？

将 demo/data/ 整体复制到新机器的对应目录，启动 bridge 后自动恢复全部书籍和标注记录。

Q：批量标注卡住，有些图像一直显示"标注中"？

刷新页面即可自动修复——系统启动时会将所有残留的"标注中"状态重置为"待标注"或"待确认"，不会丢失已完成的结果。也可在「⚡ 标注队列」页面查看当前进度、暂停或取消批次。
