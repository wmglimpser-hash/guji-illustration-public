# 医图志公开展示站

`showcase/` 是标注工作台的只读展示层，用于浏览已经审核并允许公开的古籍插图记录。

本目录只包含静态站代码，不随公开镜像分发真实展示数据、古籍整页扫描图或裁剪插图。生成的公开数据应写入被忽略的 `showcase/data/`，并在发布前逐项核对来源、审核状态和图像权利。

## 本地预览

```bash
python ../scripts/serve_static_nocache.py --directory . --port 7901
```

然后访问 `http://127.0.0.1:7901/`。

没有生成 `showcase/data/` 时，页面不会展示生产数据。

## 发布边界

- 只导出人工确认且明确允许公开的记录。
- 不发布 AI 原始响应、审核备注、内部版本信息和本地文件路径。
- 图像来源与权利声明必须按具体底本记录。
- 公开展示数据不能反向写入标注工作库。
