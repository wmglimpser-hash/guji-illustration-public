# 医图志 · 卷三全卷标注体验

**[点击进入在线 Demo](https://yituzhi-annotation.glimpser45.chatgpt.site)**

《补遗雷公炮制便览》卷三全卷160页，可浏览全部书页、连续翻页和按页码跳转。

甘草、炮製甘草两条预置 AI 候选用于体验校文、调框、图文互证和人工审核。修改保存在当前浏览器，可导出和重置。OCR 底稿与 AI 候选均为预置结果。

本地预览：在本目录执行 `python3 -m http.server 7910 --bind 127.0.0.1`，打开 http://127.0.0.1:7910/ 。
