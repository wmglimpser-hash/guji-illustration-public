## 1. 权威来源说明

本项目插图分类体系采用：

> 胡晓峰.《历代中医古籍图像类编》. 北京: 科学出版社, 2017.

该书系统梳理历代中医古籍图像，将其划分为 **12 大类**，是目前学界覆盖最全、最具权威性的中医古籍图像分类框架，也是本项目 AI Prompt 和人工标注的直接依据。

补充参考：
- 孙清伟、胡晓峰（2014）《试述中医本草古籍图像种类》— 9 类前身方案
- 郑晓雯等（2022）《〈本草图经〉草部、木部的药图类型初探》— 植物药图细分参考

## 2. 12 大类分类体系

### 2.1 分类总览

| 编号 | 类别名称 | 典型内容 |
|------|---------|---------|
| 1 | **疾病图** | 病位图、病形图、病因图 |
| 2 | **诊法图** | 脉诊图、望诊图 |
| 3 | **医疗图** | 疗法图、推拿图、复位图 |
| 4 | **药物图** | 药物形态图、药物炮制图、药物关联图 |
| 5 | **器具图** | 医疗器具、药物加工器具 |
| 6 | **养生图** | 练功图、导引图、拳法图 |
| 7 | **脏腑图** | 五脏六腑形态图、内景图 |
| 8 | **经穴图** | 全身经脉图、局部经脉图、铜人图、穴位图 |
| 9 | **部位图** | 骨度图、体表部位图 |
| 10 | **理论图** | 五运六气图、太极图、命门图、星象图、子午流注图、方解图、胎产图、禁忌图、五轮八廓图 |
| 11 | **符咒图** | 祈福变形文字、符箓图形 |
| 12 | **人物图** | 作者像、医家历史人物像 |

### 2.2 各类说明与边界

**疾病图**  
描绘疾病部位、形状或发病原因。分三种子类：病位图（标注病变位置）、病形图（绘出病形外观）、病因图（说明病因机理）。  
*边界*：描绘治疗过程的归医疗图；描绘经络穴位的归经穴图。

**诊法图**  
表述望、闻、问、切等中医诊断方法。重点包括脉诊图、舌诊图、面诊图等。  
*边界*：诊断动作场景中若医生患者均有但无明确技法操作，归人物图。

**医疗图**  
绘出治疗疾病的具体方法，包括疗法、推拿、复位、针灸操作等场景。  
*边界*：不用于泛化指代药物炮制场景（炮制归药物图）；养生功法归养生图。

**药物图**
描绘药物形态（药物基原和药材）、药物炮制过程和器具，以及与药物相关内容的一大类图像。根据图像内容侧重点分为药物形态图、药物炮制图、药物关联图。
*边界*：正文提到炮制方法但图像本身只描绘药材/矿物/饮片外观时，归药物形态图；图像主体是炮制动作、流程或药物加工器具使用时，归药物炮制图；单纯描绘加工器具形态而无药物的归器具图。

**器具图**  
描绘医疗或药物加工器具的形状及使用方式，图中器具为主体。  
*边界*：器具出现在操作场景中但以操作过程为主的，归医疗图或药物图。

**养生图**  
描绘养生健身方法，包括导引术、八段锦、五禽戏等练功图，以及饮食养生场景。  
*边界*：功法与经络示意混合时，以功法动作为主则归养生图；以经络路线为主则归经穴图。

**脏腑图**  
表现五脏六腑的位置及形态，包括内景图（人体内景剖示）。  
*边界*：脏腑图若附有经络线条且经络为主体，归经穴图。

**经穴图**  
标明人体经脉循行路线及相关穴位，包括全身经脉图、局部经脉图、铜人图、单穴示意图。  
*边界*：仅标骨度或体表测量基准点的归部位图。

**部位图**  
标注骨骼或重要体表部位的位置及名称，如骨度图、仰伏人图。  
*边界*：部位图中如有经脉线条且经脉为主体，归经穴图。

**理论图**  
用图像表述中医理论，涵盖运气学说、阴阳五行、时间医学等，典型如五运六气图、子午流注图、太极图、五轮八廓图（眼科理论）、胎产图（产科理论）等。

**符咒图**  
特殊描绘的变形文字或图形，功能为祈求身体康健，具有宗教或民俗属性，区别于一般的文字或装饰图案。

**人物图**  
中医药相关人物的画像，包括作者自序像、名医画像、历史人物肖像。  
*边界*：人物出现在医疗操作场景中且以技法动作为主的，归医疗图或诊法图；人物图是人物本身为主体（肖像性质）。

### 2.3 两大归属提醒（辅助理解，不覆盖直接证据）

| 归属 | 类别 |
|------|------|
| **学科通用图像** | 诊法图、脏腑图、经穴图、部位图、理论图、符咒图、人物图 |
| **学科特色图像** | 疾病图、医疗图、药物图、器具图、养生图 |

## 3. 细分类（二级分类）

### 3.1 疾病图

| 子类 | 说明 |
|------|------|
| 病位图 | 标注病变发生的位置 |
| 病形图 | 绘出病症的外观形态 |
| 病因图 | 说明病因或发病机理 |

### 3.2 诊法图

| 子类 | 说明 |
|------|------|
| 脉诊图 | 切脉部位、脉象示意 |
| 望诊图 | 舌诊、面诊、望色等 |

### 3.3 医疗图

| 子类 | 说明 |
|------|------|
| 疗法图 | 针灸、艾灸、拔罐等治疗操作 |
| 推拿图 | 推拿手法示意 |
| 复位图 | 正骨、复位手术操作 |

### 3.4 药物图

| 子类 | 说明 |
|------|------|
| 药物形态图 | 直接描绘药物整体、入药部位、药材饮片、植物/动物/矿物药外观形态，便于辨识药物；正文提到炮制但图像本身没有炮制动作或加工场景时仍归本类 |
| 药物炮制图 | 描绘药物加工炮制方法、工艺流程或相关器具使用；出现人物处理药物，或炒、煅、煮、蒸、炙、洗、晒、研、捣、切、炼、熬等操作场景时归本类 |
| 药物关联图 | 以药物为中心拓展表达生态环境、产地、运用、民俗、神话传说、对外交流、文学作品等内容；不直接描绘药物形态或炮制过程 |

### 3.5 经穴图

| 子类 | 说明 |
|------|------|
| 全身经脉图 | 十四经脉完整循行 |
| 局部经脉图 | 单经或局部经脉 |
| 铜人图 | 铜人腧穴标注图 |
| 穴位图 | 单穴或多穴示意 |

### 3.6 理论图（举要）

| 子类 | 说明 |
|------|------|
| 五运六气图 | 运气学说示意 |
| 子午流注图 | 时间针灸理论 |
| 太极图 | 阴阳理论图示 |
| 五轮八廓图 | 眼科理论示意 |
| 胎产图 | 产科理论示意 |
| 星象图 | 与医学相关的星象图 |

## 4. 图文关系字段

`text_image_relation` 是独立于图像分类的核心字段，反映图像与页面文字之间的对应程度：

| 取值 | 含义 |
|------|------|
| **一致** | 图像准确反映文字描述的内容 |
| **存疑** | 图文关系存在不确定性，需进一步核查 |
| **矛盾** | 图像与文字存在明确冲突或错误 |

该字段由 AI 初步判断（`annotation.aiVerdict`），人工可修改（`crossref.verdict`）。两者独立存储，导出时均保留。

### 4.1 判定细则

| 取值 | 纳入标准 | 不应据此判定 |
|------|----------|--------------|
| **一致** | 题签、图像主体、页面邻近文字或已确认的对应原文，至少一项能够直接支持核心对象或图示内容，且没有发现明确冲突 | 图像比文字表现得更丰富，不等于矛盾；文字中的次要内容未全部画出，也不自动构成矛盾 |
| **存疑** | 题签漫漶、裁图边界不清、多条文字并列而归属不明、文字证据缺失，或现有证据不足以判断一致或矛盾 | 不得因模型置信度低直接判为存疑，应说明具体证据缺口 |
| **矛盾** | 文字与图像在核心对象、数量、方位、操作关系或题签归属上出现可明确核实的互斥信息 | 单纯缺少细节、图像补充文字未记内容、OCR 错字或现代命名差异，不直接构成矛盾 |

### 4.2 常见边界情形

- **题签漫漶不可辨**：若仍可由页面位置和对应原文确定归属，可判“一致”；否则判“存疑”，不得猜测题签。
- **同页存在多个条目**：优先依据已确认裁图范围、题签位置和邻近文字建立对应；无法唯一对应时判“存疑”。
- **图像内容超出文字记载**：视为图像的补充信息，不因“画得更多”判“矛盾”。
- **文字内容未全部在图像体现**：先判断插图是否只承担选择性示意；只有缺失内容使核心对象或关系与文字相互排斥时，才判“矛盾”。
- **OCR 与原图不一致**：图文关系判断以原页可见文字和人工确认的对应原文为准，OCR 只作检索与定位辅助。

## 5. 版刻与绘制特征（辅助元数据）

### 5.1 绘制技法

| 名称 | 说明 |
|------|------|
| 线描 | 以线条为主，单色墨线 |
| 彩绘 | 设色图像，多层晕染 |
| 水墨 | 墨色浓淡变化，写意风格 |
| 套印 | 朱墨套印或多色套印 |
| 其他 | 无法归入以上类别 |

### 5.2 书页版式

| 类型 | 说明 |
|------|------|
| 图居左，文字在右 | 图文并排布局 |
| 图居上，文字在下 | 上图下文布局 |
| 整页图后附文 | 图占整页，说明文字在另页 |
| 合页连式 | 图像跨两页对折展示 |

## 6. 与旧体系的对照（附录 A）

v2.0 使用自建 8 类英文代码，面向本草图谱类书籍设计，已不作为本项目标准体系。对照关系如下：

| 旧 8 类（v2.0） | 现 12 类对应（v3.0） | 说明 |
|----------------|---------------------|------|
| PLANT（植物药图） | 药物图 > 药物形态图 | 植物药材归入药物图 |
| ANIMAL（动物药图）| 药物图 > 药物形态图 | 动物药材归入药物图 |
| MINERAL（矿物药图）| 药物图 > 药物形态图 | 矿物药材归入药物图 |
| PROCESSED（炮制加工图）| 药物图 > 药物炮制图 | 炮制场景归入药物图；若图像只是药材/矿物/饮片外观，仍按药物形态图处理 |
| HUMAN_BODY（人体结构图）| 经穴图 / 脏腑图 / 部位图 | 按主体内容细分 |
| MEDICAL_PRACTICE（医疗技法图）| 医疗图 / 诊法图 | 按诊断/治疗细分 |
| LIFESTYLE（养生保健图）| 养生图 | 直接对应 |
| PERSON_SCENE（人物场景图）| 人物图 | 人物肖像类对应 |

旧字段 `legacy_type_guess` 在导出数据中保留，仅供兼容参考，不作为统计主字段。
