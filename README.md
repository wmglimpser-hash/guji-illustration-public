# 医图志 · 卷三真实工作快照

[在线打开标注系统](https://wmglimpser-hash.github.io/guji-illustration-public/)

《补遗雷公炮制便览》卷三全卷160页、160页OCR、32页人工修订、96个已确认插图页；保存128条标注记录，包括112条已确认的当前图项和16条拆分前的整页历史记录（原状态为待审核）。保留原有插图选框、旋转、分图、AI初稿、当前标注、图文证据和审核修改记录。

页面上方可进入校文、调整插图框、查看已有标注和审核记录。体验修改保存在当前浏览器，可导出；“恢复工作快照”恢复发布时的原始记录。在线版使用已保存的OCR和AI结果。

本地预览：在本目录执行 `python3 -m http.server 7910 --bind 127.0.0.1`，打开 http://127.0.0.1:7910/ 。
